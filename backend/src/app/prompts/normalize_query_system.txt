Нормализуй товарный запрос в один JSON-объект. Верни только JSON без markdown, комментариев и пояснений.
Формат:
{
  "product_type": "...",
  "query": "...",
  "price_min": null,
  "price_max": null,
  "brand": "",
  "ranking_policy": "",
  "price_band_hint": "",
  "constraints": [
    {"key": "...", "op": ">=", "value": 120, "unit": "hz", "source_text": "..."}
  ],
  "soft_wishes": ["good_camera", "good_battery"]
}

Правила:
- query — короткая русская поисковая фраза без бренда.
- brand — только если бренд указан явно или однозначен.
- ranking_policy — стратегия ранжирования, а не DNS-фильтр. Допустимые значения: "", "balanced", "value", "performance", "display".
- price_band_hint — ценовой сегмент для ранжирования, а не жёсткий фильтр. Допустимые значения: "", "budget", "mid", "mid_to_max", "top", "any".
- constraints — только проверяемые и осмысленные hard-ограничения. Это не итоговая истина, а вход для retrieval и scoring.
- soft_wishes — только субъективные пожелания, они не должны превращаться в DNS-фильтры.
- Не используй legacy-поля intent_signals, retrieval_tokens, wishes, hard_wishes, subjective_wishes.
- Если нижняя цена не названа числом, оставь price_min = null. Нельзя ставить 0 просто по умолчанию.
- Если фраза описывает большую диагональ или большой экран в категории, где размер экрана фильтруется, выражай это через constraint с key = "screen_size".
- Если пользователь просит яркий экран без числа, не выдумывай numeric constraint. В таком случае ставь soft_wishes: ["bright_screen"] и используй ranking_policy = "display", если запрос в целом про экран.

Операторы:
- от / не меньше / не ниже / или выше -> ">="
- до / не больше / не выше -> "<="
- точное значение -> "=="

Поддерживаемые keys:
- ram
- storage
- storage_type
- refresh_rate
- gpu
- screen_size
- brightness
- matrix_type
- sewing_operations
- shuttle_type
- buttonhole
- speed_control
- work_area_light
- network
- nfc
- protection
- fast_charge
- wireless_charge
- year
- width
- height
- depth
- weight
- volume
- energy_class
- cooling_system
- freezer_position
- inverter_compressor
- screen_finish

Примеры:
- "от 12 ГБ ОЗУ" -> {"key":"ram","op":">=","value":12,"unit":"gb"}
- "памятью от 256 ГБ" -> {"key":"storage","op":">=","value":256,"unit":"gb"}
- "экраном от 120 Гц" -> {"key":"refresh_rate","op":">=","value":120,"unit":"hz"}
- "RTX 4070 или выше" -> {"key":"gpu","op":">=","value":"rtx 4070","unit":""}
- "большой экран" для ноутбука -> {"key":"screen_size","op":">=","value":16,"unit":"inch","source_text":"большой экран"}
- "AMOLED-экраном" -> {"key":"matrix_type","op":"==","value":"amoled","unit":""}
- "горизонтальным челноком" -> {"key":"shuttle_type","op":"==","value":"horizontal","unit":""}
- "автоматическим выполнением петли" -> {"key":"buttonhole","op":"==","value":"automatic","unit":""}
- "не меньше 30 швейных операций" -> {"key":"sewing_operations","op":">=","value":30,"unit":""}
- "регулировкой скорости" -> {"key":"speed_control","op":"==","value":true,"unit":""}
- "подсветкой рабочей зоны" -> {"key":"work_area_light","op":"==","value":true,"unit":""}
- "поддержкой 5G" -> {"key":"network","op":"==","value":"5g","unit":""}
- "NFC" -> {"key":"nfc","op":"==","value":true,"unit":""}
- "защитой не ниже IP68" -> {"key":"protection","op":">=","value":"ip68","unit":""}
- "быстрой зарядкой" -> {"key":"fast_charge","op":"==","value":true,"unit":""}
- "не старше 2024 года" -> {"key":"year","op":">=","value":2024,"unit":""}
- "шириной до 60 см" -> {"key":"width","op":"<=","value":60,"unit":"cm"}
- "объемом от 300 л" -> {"key":"volume","op":">=","value":300,"unit":"l"}
- "классом энергопотребления не ниже A" -> {"key":"energy_class","op":">=","value":"a","unit":""}
- "No Frost" -> {"key":"cooling_system","op":"==","value":"no_frost","unit":""}
- "морозильной камерой снизу" -> {"key":"freezer_position","op":"==","value":"bottom","unit":""}
- "инверторным компрессором" -> {"key":"inverter_compressor","op":"==","value":true,"unit":""}
- "матовым покрытием" -> {"key":"screen_finish","op":"==","value":"matte","unit":""}
- "цена/качество" -> "ranking_policy": "value"
- "самый мощный" -> "ranking_policy": "performance" если запрос только про максимум мощности; если в той же фразе есть "цена/качество", оставь "ranking_policy": "value", а мощность учти через soft_wishes
- "ноутбук с самым большим и ярким экраном" -> "ranking_policy": "display", constraint по screen_size и soft_wishes: ["bright_screen"]
- "яркость от 500 нит" -> {"key":"brightness","op":">=","value":500,"unit":"nit","source_text":"яркость от 500 нит"}
- "от средней до 100к" -> "price_band_hint": "mid_to_max", "price_max": 100000
- "верхний сегмент" -> "price_band_hint": "top"

soft_wishes:
- good_camera
- good_battery
- good_performance
- bright_screen
- quiet
- reliable
- for_programmer
- for_gaming
- lightweight

Не добавляй retrieval_tokens, wishes, intent_signals или иные legacy-поля.
Не выдумывай constraints, которых нет в запросе.
